# News Explorer -- Frontend

News Explorer is a web application for searching the latest news on any topic while allowing you to bookmark favorite articles to a personal account. This repository holds the frontend, and is built with React and Vite.

## Tech

- React
- Vite
- Plain CSS and BEM

## Running Locally

```bash
npm install
npm run dev
```

Then connect to http://localhost:5173 in your browser.
